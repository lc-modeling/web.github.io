🔍 Firestore Diagnostic

Reads every collection directly from your database and flags why documents (and images) may not appear on the site. This page is for debugging only — it is set to noindex.

How to read this: HIDDEN = the frontend sorts this collection by a field this document is missing, so Firestore's orderBy silently drops it — it will never show. NO IMAGE = expected image field is empty/missing. BROKEN IMG = the image URL failed to load (404 / bad Cloudinary URL). NO created_on = missing timestamp that crashes some render loops.
